Política de Privacidade · Privacy Policy

Máquina de Conteúdo · Última atualização / Last updated: 29/09/2026

Português

Quem usa: a Máquina de Conteúdo é uma ferramenta privada, usada somente por mim (João), no meu próprio computador, para os meus próprios canais do YouTube. Não há outros usuários.

Dados acessados: por meio dos Serviços de API do YouTube, a ferramenta acessa apenas os meus canais: envia vídeos, miniaturas, legendas e playlists, e lê as estatísticas desses canais (visualizações, tempo de exibição, inscritos e dados agregados de audiência fornecidos pelo YouTube Analytics). Nenhum dado de outros usuários ou canais é coletado.

Uso e armazenamento: os dados de estatísticas são usados somente para gerar um relatório semanal privado de desempenho dos meus canais, para mim mesmo. Os dados brutos ficam armazenados no meu computador. As credenciais de acesso (tokens OAuth) ficam guardadas localmente e nunca são compartilhadas.

Prestadores de serviço: para produzir e me entregar esse relatório, a ferramenta usa três serviços que processam os dados somente em meu nome: (1) a Anthropic (Claude), que lê as estatísticas agregadas dos meus canais para escrever a análise e as sugestões do relatório; (2) o Telegram, que entrega o resumo do relatório apenas no meu próprio celular; (3) o GitHub Pages, que hospeda o painel do relatório criptografado (AES-GCM), legível só com uma senha que apenas eu tenho.

Compartilhamento: nenhum dado é vendido, publicado ou compartilhado com terceiros para qualquer outro fim. Nenhum dado de espectadores individuais é acessado: o YouTube Analytics só fornece números agregados.

Cookies: este site não usa cookies nem ferramentas de rastreamento.

Retenção e exclusão de dados: os dados obtidos pela API ficam guardados no meu computador (e, criptografados, no painel), somente pelo tempo necessário para gerar e comparar os relatórios semanais. Dados que não sejam estatísticas dos meus próprios canais são atualizados ou excluídos em até 30 dias. Se a autorização for revogada, todos os dados obtidos pela API são excluídos em até 7 dias, inclusive do painel. Pedidos de exclusão podem ser feitos pelo e-mail de contato abaixo.

Revogar acesso: o acesso pode ser revogado a qualquer momento em Permissões da Conta Google.

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

English

Who uses it: Máquina de Conteúdo is a private tool used only by me (João), on my own computer, for my own YouTube channels. There are no other users.

Data accessed: through the YouTube API Services, the tool accesses only my own channels: it uploads videos, thumbnails, captions and playlists, and reads those channels' statistics (views, watch time, subscribers and aggregated audience data provided by YouTube Analytics). No data from other users or channels is collected.

Use and storage: analytics data is used only to build a private weekly performance report about my own channels, for myself. The raw data is stored on my computer. Access credentials (OAuth tokens) are stored locally and are never shared.

Service providers: to produce and deliver that report to me, the tool uses three services that process the data only on my behalf: (1) Anthropic (Claude), which reads my channels' aggregated statistics to write the report's analysis and suggestions; (2) Telegram, which delivers the report summary only to my own phone; (3) GitHub Pages, which hosts the report dashboard encrypted (AES-GCM), readable only with a password that only I have.

Sharing: no data is sold, published or shared with third parties for any other purpose. No data about individual viewers is accessed: YouTube Analytics only provides aggregated numbers.

Cookies: this site uses no cookies or tracking tools.

Data retention and deletion: data obtained through the API is kept on my computer (and, encrypted, in the dashboard), only for as long as needed to generate and compare the weekly reports. Any data other than my own channels' statistics is refreshed or deleted within 30 days. If authorization is revoked, all data obtained through the API is deleted within 7 days, including from the dashboard. Deletion requests can be sent to the contact e-mail below.

Revoking access: access can be revoked at any time at Google Account permissions.

This tool uses the YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.
