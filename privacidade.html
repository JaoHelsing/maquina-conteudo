Máquina de Conteúdo · Última atualização / Last updated: 25/09/2026

Português

Quem usa: a Máquina de Conteúdo é uma ferramenta privada, usada somente por mim (João), no meu próprio computador, para os meus próprios canais do YouTube. Não há outros usuários.

Dados acessados: por meio dos Serviços de API do YouTube, a ferramenta acessa apenas os meus canais: envia vídeos, miniaturas, legendas e playlists, e lê as estatísticas desses canais (visualizações, tempo de exibição, inscritos e dados agregados de audiência fornecidos pelo YouTube Analytics). Nenhum dado de outros usuários ou canais é coletado.

Uso e armazenamento: os dados de estatísticas são usados somente para gerar um relatório privado de desempenho e ficam armazenados apenas no meu computador. As credenciais de acesso ficam guardadas localmente e nunca são compartilhadas.

Compartilhamento: nenhum dado é vendido, compartilhado ou transferido a terceiros.

Cookies: este site não usa cookies nem ferramentas de rastreamento.

Revogar acesso: o acesso pode ser revogado a qualquer momento em Permissões da Conta Google.

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

English

Who uses it: Máquina de Conteúdo is a private tool used only by me (João), on my own computer, for my own YouTube channels. There are no other users.

Data accessed: through the YouTube API Services, the tool accesses only my own channels: it uploads videos, thumbnails, captions and playlists, and reads those channels' statistics (views, watch time, subscribers and aggregated audience data provided by YouTube Analytics). No data from other users or channels is collected.

Use and storage: analytics data is used only to build a private performance report and is stored only on my computer. Access credentials are stored locally and are never shared.

Sharing: no data is sold, shared or transferred to third parties.

Cookies: this site uses no cookies or tracking tools.

Revoking access: access can be revoked at any time at Google Account permissions.

This tool uses the YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.
